
# Paradise Nursery - Online Plant Shop

## Project Name
Paradise Nursery Plant Shop Application

## Project Description
Paradise Nursery is an online plant shopping application where users can explore a variety of indoor plants, view product details, add plants to their shopping cart, manage quantities, and remove items from their cart.

## Features
- Browse plants by category.
- View plant names, images, and prices.
- Add plants to the shopping cart.
- Increase or decrease item quantities.
- Remove plants from the cart.
- View total items and total price.

## Technologies Used
- React.js
- JavaScript
- Redux Toolkit
- CSS
- HTML

## Application
Paradise Nursery provides a simple and user-friendly shopping experience for plant lovers.
